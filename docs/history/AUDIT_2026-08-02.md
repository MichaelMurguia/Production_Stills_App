# Code Audit — 2026-08-02

Full-codebase audit of both apps, run against release 2026.08.01.33.
Two independent passes: the product app (`app/*.py`, `app/static/app.js`,
`scripts/`) and the storefront/tenant infrastructure (`storefront/`).
Every finding below was verified against the code before being fixed;
**all fixes shipped in release 2026.08.02.34** with regression tests
(`tests/test_audit_fixes.py`, `storefront/tests/test_audit_fixes.py`).

Companion docs written in the same pass: `INTENT.md` (product intent &
usage), `ARCHITECTURE.md` (module map, data layout, flows),
`TEST_MATRIX.md` (coverage review).

## Storefront & tenant infrastructure — 20 findings, all fixed

Severity-ordered; file references are post-fix.

1. **Webhook fulfilled unpaid sessions.** `checkout.session.completed`
   fires for delayed-payment methods still pending; `_fulfill` ran
   regardless — licenses for money that never arrives. Now gated on
   `payment_status ∈ {paid, no_payment_required}`;
   `async_payment_succeeded` handled. (`main.py` webhook)
2. **OAuth login-CSRF.** The `state` value was signed but not bound to
   the browser and never expired. Now: expiring signed state + a
   same-site state cookie; the callback requires both to match.
   (`auth.py make_state/check_state`, `main.py /auth/google*`)
3. **Canceled subscription could leave a studio running unbilled
   forever.** With Railway unconfigured, the CANCELED branch stamped the
   terminal REVOKED status without deleting the service. REVOKED is now
   only ever stamped after the delete succeeds; the unconfigured case
   states "cancel pending" and retries. (`provisioner.py`)
4. **Subdomain claim race.** Check-then-set with no DB constraint — two
   simultaneous claims could both win. Now a partial unique index
   (`WHERE subdomain <> ''`) referees; the route maps IntegrityError to
   "that name is taken"; random-slug assignment retries. (`db.py`,
   `main.py`, `provisioner.py`)
5. **Concurrent `reconcile()` double-provisioning.** Spawned from
   startup, /success, the webhook, and naming with no mutual exclusion.
   Now a non-blocking process lock — overlapping calls skip.
6. **Session cookie `Secure` flag trusted the request scheme**, which
   reads `http` behind Railway's TLS terminator. Now forced when
   BASE_URL is https. (`_cookies_secure`)
7. **Proxy allowlist parse was bypassable** —
   `https://evil.com?x=.up.railway.app` passed the `endswith` check on a
   string-sliced netloc. Now `urlsplit().hostname`. (`tenant_proxy.py`)
8. **`available_versions()` 500 on mixed version segments** (int/str
   comparison in the sort key). Typed tuple key.
9. **`_fulfill` race → buyer-facing 500.** Webhook and /success
   fulfilling the same session concurrently hit the unique constraint
   uncaught. Now caught; the winner's row is returned.
10. **No refund/dispute handling.** `charge.refunded` /
    `charge.dispute.created` now flip the purchase to REFUNDED via the
    stored `stripe_payment_intent` (new column); the download gate
    already respects status, and reconcile revokes REFUNDED cloud
    studios.
11. **Sync DB queries on the event loop** in the per-request middleware
    and the proxy's host lookup — threadpooled.
12. **FAILED provisioning looked like "setting up" forever.** The
    success page poll and the account page now state the snag and that
    retries continue.
13. **Admin tokens rode in GET query strings** (access logs). All four
    /admin endpoints now also accept `Authorization: Bearer`.
14. **/auth/email unthrottled; LoginToken rows accumulated forever.**
    One mail/minute/address (uniform response preserved) + opportunistic
    purge of dead tokens.
15. **/success 500 on garbage session ids.** Stripe errors now redirect
    home.
16. **REVOKED workspaces squatted claimable names** (clash check counted
    them; the router already 404'd them as unclaimed). Revoke now
    releases the subdomain.
17. **Proxy forwarded spoofable inbound `X-Forwarded-*`.** Inbound
    chain stripped; the proxy writes its own host/proto and adds
    `X-Forwarded-For`.
18. **Websocket scopes on tenant hosts fell through to the storefront.**
    Now refused (close 1008).
19. **`init_db` swallowed every migration error** — a down DB served
    with unmigrated tables. Only duplicate-column/index errors are
    swallowed; connectivity failures are loud.
20. **Dead code:** `railway.create_custom_domain` (unused since the
    wildcard-router design) removed.

Verified clean: template XSS (autoescape throughout), POST CSRF
(SameSite=Lax), CI pipeline, proxy streaming.

## Product app — 25 findings, all addressed

1. **Cross-production race on the path globals.** `set_project()`
   mutates module globals; the projects-summary sweep repoints them
   through every production while threadpool work (a 30–120 s render)
   may be in flight. Now `paths.SWITCH_LOCK` makes the sweep atomic
   against switches, and counter allocation shares the same lock so an
   id can never be minted against the wrong production. (The full
   parameter-threading refactor remains the long-term shape; this
   closes the corruption window.)
2. **`renderAssembly()` crashed on the land-on-board path**
   (`orderedBoards` out of scope — `ReferenceError` after every
   assemble from the Boards view). Fixed to the in-scope collection.
3. **"Generate all samples" crashed when any key had a failed test**
   (out-of-scope variables in a copy-pasted block). Block removed; the
   handler now states why nothing can run.
4. **Saving a breakdown silently wiped model-authored data** — panel
   `scale`/`evidence`/`composition_role` and ledger
   `confidence`/`rationale` were hardcoded on every Save (including the
   implicit Save inside Validate and Approve-&-lock). Originals now
   carry through; only user-edited fields change.
5. **`slug` reached the filesystem unvalidated** on
   `/api/projects/activate` and `/api/projects/backup` (absolute paths
   escaped the projects dir on Windows). `paths.safe_id` now guards
   both.
6. **Custom-engine URL fetch was an SSRF** (`urlopen` on any scheme, no
   timeout, no size cap — `file://` reads into a served artifact).
   https/http only, 120 s timeout, 64 MB cap.
7. **Board canvas dimensions were unbounded** — 60000×60000 ≈ 10 GB
   allocation; tiny heights crashed the aspect solver. `check_canvas`
   states 1024–8192 × 576–8192 on both the slot map and assembly.
8. **Aspect layout is exponential in panel count** and sits on the
   dashboard hot path (`blocking()` → `slot_map` per locked sheet).
   Above 12 panels it now falls back to the grid grammar.
9. **Counter allocation was a read-modify-write race** (candidates,
   boards, references). `store.next_counter` allocates under the lock.
10. **Reference ids could be reused after a crash** (counter persisted
    last). The counter now persists at allocation.
11. **State files written non-atomically / read unguarded** — a
    truncated `settings.json` 500'd every route including the Settings
    page needed to fix it. All state writes route through
    `_atomic_write_json`; corrupt `settings.json`/`subjects.json` are
    set aside as `.corrupt` (nothing destroyed) instead of bricking the
    app.
12. **Scene Scan cache leaked across productions** —
    `localStorage["wizardAnalysis"]` was not namespaced; switching films
    grouped locations by the previous film's environments. Now keyed
    per production slug like all other UI state.
13. **Restore could leave a half-written production** and trusted
    attacker-controlled header sizes. Restores now stream with a hard
    byte budget into a hidden staging dir renamed into place on success;
    dot-led dirs never appear on the shelf.
14. **`_spec_path` admitted `..`** — `delete_spec` builds an rmtree
    target from it; only call order stood between that and `data/`
    deletion. `safe_id` now guards inside `_spec_path` itself.
15. **Workspace session cookie without `Secure` on hosted tenants**
    (uvicorn didn't trust Railway's proxy headers, so the scheme read
    http). Railway presence now forces Secure, and the provisioner sets
    `FORWARDED_ALLOW_IPS=*` on tenant services.
16. **Crop endpoint 500 instead of 404** on traversal-shaped ids —
    KeyError now mapped like every other candidate route.
17. **Model JSON assumed to be an object** — a top-level list became a
    bare 502. `_parse_json` now states a 422.
18. **Quarantine was advisory** — `reference_image_path` searched the
    quarantine folder for active records, so an index/disk disagreement
    served a rejected file. Quarantine now resolves only for REJECTED
    records or explicit opt-in.
19. **View dispatch honored prototype-inherited keys** (`#toString`
    rendered nothing and persisted). `Object.hasOwn` on both dispatch
    sites.
20. **Duplicate-board guard went stale on variant switch** — the guard
    now recomputes inside `refreshMap`.
21. `subjects.json` was re-read once per required object per prompt —
    hoisted.
22. Pillow file handles stayed open across model calls (Windows locks) —
    images are loaded and released before the call.
23. Two escaping slips: a double-escaped toast and the one un-`esc`'d
    interpolation in the sheet editor (self-XSS only) — fixed.
24. Dead constants removed (`HEADER_H`, `SPEC_STATUSES`,
    `STYLE_ROLES`/`reference_kind`, `BOARD_TYPES`, `TIMES_OF_DAY`).
25. Leftover hardcoded film name in `scripts/compile_prompt.py` /
    `validate_spec.py` descriptions — genericized (the no-hardcoded-
    project rule).

Verified clean: `esc()` discipline across ~5.5k lines of `app.js` (the
two slips above were the only gaps, neither exploitable), backup
zip-slip guards, activity-log secret redaction.
