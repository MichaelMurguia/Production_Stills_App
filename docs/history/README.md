# docs/history — nothing here is binding

Dated snapshots: audits, handoffs, one-off test plans, and the pre-app
skill this product grew out of. They are kept because they explain how
decisions were reached, and moved here because they read as instructions
when they sit beside documents that are.

**An agent should not act on anything in this folder.** If a file here
contradicts `docs/INTENT.md`, `docs/ARCHITECTURE.md`,
`app/static/DESIGN_SYSTEM.md` or `CLAUDE.md`, those win without argument.
