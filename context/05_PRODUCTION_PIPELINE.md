# Production Pipeline

```text
Screenplay and approved sources
  -> research
  -> evidence extraction
  -> asset dossiers
  -> evidence ledger
  -> canon budget
  -> adaptive layout
  -> Production Generation Specification
  -> adversarial review
  -> validation
  -> prompt compilation
  -> candidate render
  -> image audit
  -> continuity audit
  -> user approval
  -> canon update
```

The Production Generation Specification is versioned and renderer-agnostic. The compiled prompt is disposable.
