# Canon Budget

## Canon Extraction

| Class | Budget |
|---|---:|
| SCRIPT_EXPLICIT | unlimited |
| SCRIPT_NECESSARY_INFERENCE | unlimited |
| VISUAL_CANON_LOCKED | unlimited |
| USER_DIRECTED | unlimited |
| STRONG_INFERENCE | unlimited, but challenged |
| WEAK_INFERENCE | maximum 2 across the board |
| PROPOSED_NOT_CANON | 0 |
| UNSUPPORTED | 0 |

## Design Exploration

`PROPOSED_NOT_CANON` is allowed but must be visibly labeled and isolated from approved canon. Unsupported content remains prohibited.
